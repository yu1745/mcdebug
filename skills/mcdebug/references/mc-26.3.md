# Minecraft 26.3

适用于 26.3 线的 Fabric 与 NeoForge 模组。通用工作流见 [SKILL.md](../SKILL.md)，本文只写本版本的差异。

## 环境与安装

| | |
|---|---|
| 游戏 JDK | **25**（构建与运行都需要） |
| Fabric | Loader 0.20.1、Fabric API 0.166.2+26.3 |
| NeoForge | 26.3.0.103 |
| 模组 JAR | `mcdebug-fabric-26.3-<version>.jar`、`mcdebug-neoforge-26.3-<version>.jar`（均内嵌 Kotlin 标准库） |

```bash
mcdebug jar --mc 26.3 --loader fabric   --output <gameDir>/mods   # --mc 26.3 与 --loader fabric 都是默认值
mcdebug jar --mc 26.3 --loader neoforge --output <gameDir>/mods
```

`mcdebug status` 的 `mcVersion` 为 `26.3`，`modLoader` 为 `fabric` 或 `neoforge`。
CLI 用旧版模组时功能按旧模组为准；本版本相对 1.21.1 新增的能力在下文标注。

## 与其他版本的差异

- **键码**：26.3 的输入后端是 SDL。CLI 的 `gui key --key` 仍接受 GLFW 键名与数值键码
  （`ESCAPE`、`F3`、`257` 等），由模组转换为 SDL 事件；鼠标按钮编号沿用 0 左键 / 1 右键 / 2 中键。
  CLI 层格式与 1.21.1、1.20.1 完全一致，脚本无需区分。
- **GUI 输入只派发给 Screen**：`gui key` / `type` / `drag` 不注入全局输入，没有打开的 Screen 时返回 `-32020`。
- **`reflect.*` 名称**：两个加载器在开发与生产环境都使用 Mojang 官方名称；只有 Fabric 额外支持短类名
  （构建时生成的类名索引），NeoForge 只接受完整类名。NeoForge 不返回 `mojangClass` 字段。
- **存储语义**：NeoForge 使用事务型 `ResourceHandler` / `EnergyHandler` / `ItemAccess`，
  物品与流体搬运在同一事务内提交或回滚；Fabric 使用 Transfer API 的 `Transaction`。
  两个加载器的 `storage.transfer` 都是"目标收不下则整笔不发生"。
- **截图读回**：使用原版异步 GPU 读回（OpenGL 或 Vulkan 均可），`graphics` 字段报告实际后端。
  `gui.status.graphics` 之外的渲染诊断（`--draw-log`、`--annotate`）与 1.21.1 用法相同。
- **托管会话**：Fabric（Loom）走 `--args`，NeoForge（ModDevGradle）走 init 脚本，两者都可直接 `session start`。
  托管启动默认隐藏提示弹窗（Mixin 作用于 26.3 的 `ToastManager.addToast`）。

## 命令速查

```bash
mcdebug --session dev status
mcdebug --session dev gui toasts on          # 或 session start --show-toasts
mcdebug raw --show-chat server.runCommand '{"command":"/time set day"}'
mcdebug wait until 'be[100,64,100].progress >= 100' --timeout-ticks 72000 --sprint
mcdebug raw wait.until '{"predicate":"storage[0,64,0].fluid.tanks.0.amount >= 81000","timeoutTicks":400}'
mcdebug gui hover --slot 0 --hold-shift
mcdebug reflect get --root server --path 'recipeManager.byName.keySet()' --limit 10000
```

## 开发者

源码与构建在仓库的 `versions/mc26.3/`：`./gradlew build`（Fabric，同时执行 `:neoforge:build`）、
`./gradlew :neoforge:build`；冒烟为 `versions/mc26.3/scripts/fabric-smoke.sh` 与 `neoforge-smoke.sh`。
