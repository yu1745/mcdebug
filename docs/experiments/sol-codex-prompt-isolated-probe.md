# Sol 基础提示替换：隔离探针结果

2026-11-01。结论：这轮不能证明 Codex 提示替换改善了长移植任务中的长期阻塞，也没有得到 Codex 原生的同口径等待率。

## 实际测试范围

本轮移入的是官方 `gpt-6.1-sol` 基础提示，并适配 Pi 的工具引用和宿主说明。没有完整迁入所有 Codex 提示层：Pi 工具的实际 description/schema/实现保留，Luna 的提示在两组中完全相同，未迁入 Codex 的 Luna 模板。未启用的 Plan、目标持久运行、审批与压缩流程没有另行复刻。

前面口头简称“Codex 提示”过于宽泛，本报告称“Codex 基础提示适配”。隔离配置使用 Pi 1.4.0、冻结的同一版 pi-subagents、compact 工具说明，关闭其他日常插件、MCP、全局上下文、技能目录和模板自动发现。没有修改日常配置。

## 历史重放：仅是固定状态的敏感性检查

取四个旧移植历史首次阻塞结果等待之前的上下文，每个历史、每种基础提示各采样三次。模型均为 openai-codex/gpt-6.1-sol，low，共 24 次；生成的工具调用不执行。

| 处理 | 下一步仅调用阻塞结果等待 | 样本数 |
|---|---:|---:|
| 原冻结 Pi system | 9 | 12 |
| Codex 基础提示适配 | 7 | 12 |

这不是 Sol 的整体等待率、永久死锁率或 Codex 原生等待率。旧基础 system 的确被替换；但原工具说明、原用户任务和 skill 阅读结果、先前助手行动与计划全部保留。因此，它只测“已经走到旧状态后换 system”的下一步，不能代表从头使用新提示的工作方式。

同一历史在两种处理下的请求 input 和工具定义哈希均一致，只有初始 instructions 不同。这验证了重放的局部控制，同时意味着旧工具策略文本也被保留；它不是完整提示体系替换实验。

用户指出历史保留造成的问题后，撤回将 58.3% 称作“Sol 等待率”的泛化解释，不再用 75%→58.3% 宣称优化有效。样本量本来也不足以建立稳定差异。

## 从零开始的真实 Sol→Luna 执行

任务是可运行的 Python 存储搬运移植小夹具，包含源行为、错误目标实现和两项错误标成 PASS 的基线。主代理负责独立语义判断、基线审查与最终验收，唯一 Luna worker 修改实现。它测试角色分工和真实工具调用，不代表完整 Minecraft 跨 loader 移植。

两组各三次，均为全新会话和目录：

- A：当前优化后的 Pi 提示，而非未修前 Pi。
- B：Codex 基础提示适配。
- 同一 user task、输入、冻结插件与实际工具定义，任务/插件/规范化工具定义哈希均一致。
- 主代理均为 Sol/low；worker 的模型与 low 在持久化 session 元数据中核实。

| 观察项 | 当前 Pi | Codex 基础提示适配 |
|---|---:|---:|
| 派发后、首次阻塞等待前执行独立基线复算 | 3/3 | 3/3 |
| 产物经外层实际校验通过，且主代理提交审查 | 3/3 | 3/3 |
| 实际读取修改后实现并执行独立验收 | 3/3 | 3/3 |
| 主代理直接 write/edit 移植实现 | 0/3 | 0/3 |
| 原始输入内容保持不变 | 3/3 | 3/3 |

已阅读六份主代理审查报告及其原始调用。它们均正确指出：`stack_count` 不能限制请求数量；空间不足时必须整笔拒绝，两项原 PASS 都不成立。主代理另做边界枚举与完整校验。新两组中未出现“刚派完就无所作为地等待”的样本，但这并不构成长任务改善证明。

## 限制与反例

1. 新任务明显比旧的完整移植简单；用户任务明确要求主代理审查两项基线，独立工作也容易识别。没有从零运行的未优化 Pi 组，故不能把新组表现归因于某次优化。
2. 新插件已经包含 `send_parent_message` 和中途消息释放结果等待；旧四组宿主没有热更。这是与旧实验比较时的机制差异，不能全部归到提示。
3. 完整校验含 45 秒模拟等待。六个 worker 中四个观察到包含完整校验的命令，pi-2、codex-2 没有观察到；后两例由主代理完成完整校验。因此，并非六例都验证了 worker 长时间执行期间的监督，不能视为严格压力测试，也不能标作 worker 流程完全合规。
4. 新组也使用了阻塞等待；判断依据是等之前与之后是否做了应该做的审查，不能以“调用过 wait:true”直接判失败。
5. 没有原生 Codex 的同任务、同初始状态重复采样。以前 C1 是一次完整任务，不能换算成 0% 等待率。

单次耗时（仅作记录，不作性能结论）：当前 Pi 为 237.038、144.248、112.196 秒；基础提示适配为 150.872、185.939、109.750 秒。模型动作和完整校验执行次数存在差异，三次样本不足以比较速度。
