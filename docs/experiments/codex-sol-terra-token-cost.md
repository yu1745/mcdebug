## 价格口径与复算

2026-11-01核对官方模型页。每百万tokens的Standard输入/缓存读/输出分别为Sol $2/$0.10/$10、Terra $1/$0.05/$5；缓存写单价分别$2.50/$1.25，本轮写缓存均为0。[Sol官方说明](https://developers.openai.com/api/docs/models/gpt-6.1-sol)、[Terra官方说明](https://developers.openai.com/api/docs/models/gpt-6.1-terra)。

遵循用户口径，Sol不加272k长上下文倍率。基本单价列便于统一比较；右侧另按Terra API页规则，对单请求输入>272000的请求应用输入/缓存2倍、输出1.5倍，Sol保持不变。订阅如何实际计量不能从这些API参考列推断。耗时为启动至宿主退出，首轮含resume间隙，不是净模型计算时间。

每个线程读取单调累计usage，忽略重复快照；每次实际增量与last_usage逐字段核对，全部匹配。计数器未重置，不把重复last_usage叠加。报告据最终退出日志生成，原始路径/hash/最大单请求/长请求数量在 `/home/wangyu/.cache/mcdebug-port-skill-eval/codex-sol-terra-v1/usage-cost.json`。
